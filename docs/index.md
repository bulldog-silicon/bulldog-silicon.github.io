# Pathway to Chip Design

**Bulldog Silicon** is a student-led program under the IEEE student branch at Alabama A&M University. We help students develop skills in VLSI and integrated circuit design through hands-on labs, preparing them for careers in chip design.

## Mission

Introduce students to the complete IC design flow, using open-source tools and PDK like xschem, KLayout, Verilator, SKY130. Introductory labs are intended to become a repeatable pathway for new members, and experienced participants progress toward larger ASIC and tapeout projects.

## What you'll learn

**VLSI Fundamentals:** Learn CMOS logic, transistor sizing, circuit simulation, and physical layout fundamentals.

**Practical IC Design:** Gain hands-on experience designing, simulating, laying out, and verifying integrated circuits through guided projects.

**Open-Source Tools:** Explore semiconductor design using accessible tools such as Xschem, ngspice, Magic, and Netgen.


Move through **schematic design → simulation → layout → verification → performance analysis**
